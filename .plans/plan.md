# Creating a wedding e-invite

## General instructions
- if content not given, use a placeholder

## Sections on page
- 1 main pic with title(our names, or maybe a curated pic)
- short message
- wedding date & timeline, location and other details
- RSVP section/form
- FAQ

## Form details
- Name -> string
- Attending -> boolean, maps to 'rsvp' queryparam
- Dietary -> string
- Would you like a physical invite?
    - dropdown select: 'for myself', 'for my family', 'no thanks, save your pennies'
- Relations:
    - dropdown select 'You are a ____': 'friend', ''
    - 'of': string input
